### 計測値

- 長時間稼働（Chromium、音楽＋環境音＋タイマー動作中、約90周）：ヒープ 5MB → 5MB、DOM 672 → 674 ノード
- 応答性（Chromium、ソフトウェア描画・並列実行の負荷下）：何もしない時の最長タスク 88〜100ms に対し、操作中の最長 188〜251ms（主に場面切替時の景色の生成）。単独実行では操作中の長いタスクは 58ms の1件のみ
- フレーム（ヘッドレス・GPUなし）：中央値 16.7ms（60fps）。実機の GPU での確認が必要（下記）

主な改善：起動画面の裏の描画を10fpsに、サムネイル生成は入室後、カジュアル時計の起動を1.2秒遅らせる、起動時のレイアウトのずれをなくす、読み上げ名の不一致・ラベルのない入力欄・拡大禁止の viewport を解消、meta description。

残る Performance の主因は、1ファイル（約340KB、gzip 後 約130KB）の解析と、場面（キャンバス）の描画です。どちらもアプリの性質上の負荷で、CPU 4倍低速化の条件で計測しています。

## 実機でしか確かめられないこと

自動テストは WebKit エンジンで行っていますが、iPhone 固有の挙動（音声セッション・消音スイッチ、画面ロック、キーボード、ホーム画面起動、GPU の描画速度）は実機での確認が必要です。確認項目は PR の本文にまとめています。
