# CELL+ 事業計画（月額課金の設計）

> 根拠となる調査は `docs/RESEARCH-LIFE.md`（ライフ）と `docs/RESEARCH.md`（チル・サブモニター）。数字は2026年10月時点の公開情報と二次情報によるもので、リリース前に日本の App Store で再確認すること。

## 1. 結論

- **売り方**：フリーミアム。体験期間がないと有料に移らない「ハード課金」にはしない。
  - チルとカジュアルは無料のまま入口にする。
  - 有料の **CELL+** は「入力が減る・先を知らせる・見える化」に限って課金する。
- **価格**：月 480円 ／ 年 3,600円（月額の7.5か月分）／ 買い切り 9,800円。
  - あすけんと同じ水準で、日本でサブスク疲れが出にくい「月500円未満」に収まる。
- **体験**：7日間。
  - 終了の前日に必ず通知する。
  - 自動で年額に移行させない（既存方針を維持）。
  - 課金画面はオンボーディング中に一度だけ（スキップ可）。その後は、有料の機能に触れたときだけ出す。
- **アプリの中心**：ライフの「今日のボード」と「くらしの予定（ゴミの日・家事・支払い）」。
  - 日本で最も需要が強く、自治体アプリの対応にばらつきがあり、専用アプリでの課金例も見当たらない空白の領域。

## 2. 無料と CELL+ の線引き（実装済みの機能に対応）

| 機能 | 無料 | CELL+ |
| --- | --- | --- |
| チル（8つの部屋、15曲、環境音、タイマー、タスク、リマインダー、記録） | すべて | — |
| カジュアル（時計・アラーム） | すべて | — |
| ライフ：今日の流れ（時刻順の一日、いまの線） | すべて | — |
| ライフ：くらしの予定（ゴミの日・N日ごとの家事・支払い・毎年） | 3件まで | 無制限、「今回はなし」、祝日はお休み |
| 前の晩・当日の朝のお知らせ | ○（件数の上限内） | ○ |
| ルーティン（1ステップずつ進める画面） | 1つ | 無制限、ひな形すべて |
| 習慣 | 3つ | 無制限 |
| 気分・睡眠・水分・薬のチェック | すべて | — |
| 天気 | 今日の天気・最高最低・降水 | 3時間ごとの予報、傘・洗濯・暑さのひとこと |
| 振り返り | 7日間 | 30日間、気づき（睡眠×気分など）、1年前の今日 |
| データの書き出し・端末の引っ越し | ○（既存） | ○ |

**有料にしないもの**
- お知らせそのもの、今日のボード、記録すること。
- ここを有料にすると、レビューで最も多い「基本機能の有料化」への不満に直結する。

**罪悪感を生まない設計（実装済み）**
- 連続日数は数えない。
- 週の習慣は「今週 2/3回」で表す。
- 期限を過ぎた家事は「2日過ぎています」と事実だけを出す。

## 3. 収支の見立て（1年目、保守的なシナリオ）

| 項目 | 値 | 根拠 |
| --- | --- | --- |
| ダウンロード数 | 12,000 | 月1,000件。SNS（勉強垢・作業 BGM）と App Store 検索 |
| 有料への転換 | 3.0% → 360人 | フリーミアムの中央値は2.2%。生活と集中の両方で使えることを加味 |
| 年額と月額の割合 | 7：3 | Health & Fitness の売上の約68%が年額 |
| 年間売上（税抜） | 約125万円 | 年額 252人×3,600円 ＋ 月額 108人×480円×平均7か月 |
| Apple の手数料 | 15% | App Store Small Business Program |
| 手取り | 約106万円 | |
| 固定費 | 約2万円〜6万円／年 | Apple Developer 年額。天気 API（App Store 版は WeatherKit を想定し、月50万回まで追加費用なし） |

伸ばす余地は次の3つです。
- **転換率**：オンボーディングの比較表で 3% → 5% を目指す。
- **口コミ**：PC サブモニターでの常時表示が、作業配信や勉強垢での露出につながる。
- **買い切り**：買い切りを選ぶ層（約1割と想定）の上乗せ。

## 4. 実装の残り（App Store 版で必要）

1. **課金の土台**：StoreKit 2。RevenueCat の Capacitor プラグインで、購入・復元・権利の確認を行う。
   - Web 版（PWA）は無料のまま全機能を開放する。課金の有無は「App Store 版で、無料の上限に達したとき」だけに効かせる。
2. **天気**：App Store 版は WeatherKit（ネイティブ）に切り替える。
   - Open-Meteo の無料枠は非商用に限られるため、有料アプリで使う場合は商用プランが必要。
   - Apple Weather の表記とリンクを表示する。
3. **通知**：くらし・薬・ルーティンを iOS の通知として予約する仕組みは実装済み（`Native.wanted`）。上限は64件で、7日先までを予約する。
4. **ウィジェットとスタンバイ**：今日のボードとゴミの日を、ホーム画面・ロック画面・スタンバイに出す。Swift で WidgetKit を書く。
   - 課金の理由として最も強い候補。「ロック画面を見るだけで明日がゴミの日と分かる」。

## 5. 主な指標（KPI）

- **ライフの7日継続率**：目標40%以上。くらしの予定を1件以上登録した人と、しなかった人を分けて見る。
- **くらしの予定の登録率**：初日に1件以上で60%以上。ゴミの日のひな形をオンボーディングで提示する。
- **有料への転換**：体験開始から有料へ40%、ダウンロードから有料へ3%。
- **年額の初月解約**：業界では35%。年額の初月の満足度を高めるため、1回目の振り返りを7日目に届ける。
- **通知の到達**：くらし・薬は「確実に鳴る」が信頼のすべて。App Store 版で、予約した数と配信された数の差を見る。

## 6. リスクと対策

| リスク | 対策 |
| --- | --- |
| Apple のガイドライン 4.2（Web の包み直し）で却下される | ネイティブの通知・触覚・画面を消さない機能・ウィジェットを入れて、Web 版との違いを出す（`docs/APPSTORE.md`） |
| 自治体アプリ（さんあ～る等）と比べられる | 自治体が対応していなくても使える。お知らせの時刻を自由に決められる。部屋・音楽・集中と同じアプリにまとまっている |
| 天気 API の規約 | App Store 版は WeatherKit に切り替える。Web 版は Open-Meteo（非商用の範囲） |
| 入力が面倒で続かない | ひな形（ゴミ6品目・家事4件・支払い3件・ルーティン3つ）を用意した。今後、自治体の収集カレンダーの読み込みも検討する |
| サブスク疲れ | 買い切りを用意する。解約の手順と更新日を、アプリ内で明示する |
