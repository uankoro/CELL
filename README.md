# CELL

八つの部屋で、静かに過ごす。
夜ドライブ・焚火・喫茶・縁側・基地・雪見湯・灯台・軌道の八つの部屋で、音楽と環境音に包まれながら、ポモドーロタイマー・タスク・カレンダー・リマインダー・メモ・付箋・記録を使えるチルソフトです。カジュアル表示（別デザインの時計・タスク・アラーム）と、暮らしの一日を整える**ライフ**にも切り替えられます。

iPhone の横向き（ホーム画面から全画面で）と、PC のサブモニターに置きっぱなしにする使い方を想定しています（PWA）。App Store 版の準備も進めています（`docs/APPSTORE.md`）。

## できること

### ライフ（v4 で追加。「⋯」→「ライフに切り替え」、H キー、または起動画面の「ライフで開く」）

- **今日の流れ**：ルーティン・リマインダー・カジュアルのアラーム・薬・期限が今日のタスクを、時刻順に一列で。いまの時刻に赤い線
- **くらしの予定**：ゴミの日（毎週の曜日、「毎月 第2・第4 水曜」、祝日はお休み、長押しで「今回はなし」）、N日ごとの家事（過ぎた日数を表示）、毎月の支払い、毎年の更新日。前の晩・当日の朝にお知らせ
- **天気**：いまの気温と天気、最高・最低、降水確率、3時間ごとの予報。「傘を持って出かけましょう」「洗濯日和です」「暑くなります」などひとこと（Open-Meteo、オフラインでは前回の予報）
- **ルーティン**：朝・夜・出かける前などを、一つずつ表示して分数を数える画面で。水の記録・深呼吸・集中タイマー・睡眠モードへそのまま移れるステップも
- **からだ**：気分（5段階）・睡眠（チルの睡眠モードで自動記録）・水分・薬を1タップで。習慣は連続日数を数えず、「今週 2/3回」で
- **今日のひとこと**：一行の日記。1年前・30日前の今日のひとことが下に出ます
- **振り返り**：7日間／30日間の集中・睡眠・気分・習慣・水分・くらし。データがたまると「7時間以上眠った日の気分」などの気づき
- 背景には、いまの部屋の光をぼかして敷いています（静止画なので、サブモニターに出しっぱなしでも負荷はほぼありません）

### チル

- **部屋が主役**：しばらく触れないと操作の表示は静かに消え、部屋・時計・その下の一行（実行中のタイマー、いまやること、24時間以内の次の予定）だけが残ります。画面に触れる・マウスを動かす・キーを押すと戻ります（起こした一回のタップでボタンは押されません）
- **15曲**：エレピ・フェルトピアノ・ギター・琴・オルゴール・フルートなどで、テンポも 3 拍子のワルツから 112 BPM のボサノヴァまで（その場で演奏するので、同じ曲でも毎回少しずつ違います）
- **八つの部屋**：部屋ごとの景色・時計・環境音・音楽。左上の部屋の名前から選ぶか、1〜8 キー・← → キーで切り替え
- **過ごし方**（部屋と同じシート）：勉強・作業／読書／睡眠／瞑想・深呼吸／休憩／在宅ワークのBGM／子どもの学習。部屋・音・道具をワンタップでひと揃えに
- **道具**（右下）：タイマー（ポモドーロ・好きな長さ・ストップウォッチ）、カレンダー、タスク、サウンド（音楽と環境音のミキサー、おやすみタイマー）。「その他」にリマインダー、メモと付箋、記録（7日間・月ごと）、深呼吸。広い画面では8つすべてが並びます
- **操作**：タスクは右へスワイプで完了・左へで削除（取り消し可）・長押しでメニュー。左のシートは左へはらうと閉じる
- **PC のサブモニター**：時計は画面に合わせて大きくなり、離れていても読めます。縦長のモニターや小さなウィンドウでも崩れません。Chrome / Edge では「小さな窓で表示」（W キー）で、時計・タイマー・いまやることがほかのアプリの上に浮かびます
- **一日じゅう表示しておくために**：時計が数分ごとに数 px 動いて焼き付きを防ぎ、23時〜6時は部屋を少し暗く。静止中は描画を 30fps に抑え、「省電力」ではさらに控えめに
- **知らせ**：「音で知らせない」にすると、タイマーやリマインダーは画面の縁の光で知らせます（図書館などで）。「目を休める合図」で 20 分ごとに目の休憩を
- **設定**（右上の「⋯」→ 設定、または , キー）：日本語／English、文字の大きさ、表示（自動で隠す・透明度・夜の減光・焼き付き防止・省電力・画面を消さない）、音と知らせ
- **カジュアル**：「⋯」→「カジュアル表示に切り替え」（C キー）で、別デザインの時計・タスク・アラームに（タスクは共有）

- 公開URL：<https://uankoro.github.io/CELL/>
- 対応：iPhone（iOS 16.4 以降推奨）の横向き。iPad・PC のブラウザでも動きます
- データ：すべてこの端末の中（ブラウザのローカルストレージ）に保存されます。サーバーには送りません

## GitHub Pages での公開手順

1. GitHub でこのリポジトリ（`uankoro/CELL`）を開く
2. 上部の **Settings** → 左メニューの **Pages** を開く
3. **Build and deployment** の **Source** で「**Deploy from a branch**」を選ぶ
4. **Branch** で `main`、フォルダは `/ (root)` を選んで **Save**
5. 1〜2分待つと、同じ画面の上部に公開URLが表示されます
   - 公開URL：**<https://uankoro.github.io/CELL/>**
   - リポジトリの **Actions** タブで「pages build and deployment」が緑になれば完了です

以降は `main` に変更をマージするたびに自動で再公開されます。

### 更新を配信するとき

`sw.js` 冒頭の `VERSION`（例：`'v3.0.0'`）を必ず上げてからマージしてください。
新しいバージョンのキャッシュが作られ、古いキャッシュは自動で削除されます。
アプリは「まずキャッシュから即座に表示し、裏で最新版を取得する」方式なので、更新は**次に開いたとき**に反映されます。

## iPhone のホーム画面に追加する方法

1. iPhone の **Safari** で <https://uankoro.github.io/CELL/> を開く（Chrome など他のブラウザではなく Safari で）
2. 画面下の **共有ボタン**（四角から上向き矢印のアイコン）をタップ
3. メニューを下へスクロールして **「ホーム画面に追加」** をタップ
4. 名前が「CELL」になっていることを確認して、右上の **「追加」** をタップ
5. ホーム画面の CELL アイコンから起動すると、アドレスバーのない全画面で開きます

使い方のポイント：

- **横向きで使います。** 縦向きにすると「横向きにしてください」という案内が出て操作が止まります。横に戻せば、音楽やタイマーはそのまま続きから使えます
- 画面の向きが変わらない場合は、コントロールセンターの「画面縦向きのロック」をオフにしてください
- 一度開けば、**機内モードやオフラインでも起動**できます
- 最初の「入室する」をタップすると音が出ます（iPhone の消音スイッチがオンだと聞こえない場合があります）

### データの引っ越しについて（重要）

iOS では、**Safari で開いた CELL と、ホーム画面から開いた CELL は保存場所が別**です。
Safari で使っていたタスクやメモをホーム画面版に移したいときは：

1. Safari 版で、右下のツールから **記録** → **データの引っ越し** → **書き出してコピー**
2. ホーム画面版で、同じく **記録** → **データの引っ越し** → **読み込む** に貼り付けて **上書きして読み込む**

機種変更のときも同じ手順で移せます。

## テスト

Playwright で、WebKit（Safari と同じエンジン）と Chromium の両方を、iPhone SE／標準／Pro Max の横向き・タッチ操作と、PC の画面（1920×1080・縦長 1080×1920・1366×768・小さなウィンドウ・4K）のマウス操作で自動テストしています。
プルリクエストごとに GitHub Actions（`.github/workflows/test.yml`）でも実行されます。

```sh
npm ci
npx playwright install --with-deps webkit chromium   # 初回のみ
npm test                  # すべて
npm run test:webkit       # WebKit だけ
npm run test:chromium     # Chromium だけ
```

テストはコンソールのエラー・警告が1件でも出れば失敗にしています。内容は `tests/` を参照（既存機能の総点検、PWA・オフライン、旧データの移行、ジェスチャー、新機能、英語表示、アクセシビリティ、長時間稼働、応答性）。品質の計測結果は `docs/QUALITY.md` にあります。

## ローカルで確認する

`file://` で直接開いても動きますが、Service Worker（オフライン機能）は `http(s)` でのみ有効です。

```sh
npm run serve
# → http://localhost:4173/CELL/ を開く（GitHub Pages と同じサブパス）
```

ブラウザの開発者ツールで iPhone の横向き（例：844×390）を指定すると、スマホ向けのレイアウトを確認できます。
