# CELL

集中と休息のための、八つの部屋。
夜ドライブ・焚火・喫茶・縁側・基地・雪見湯・灯台・軌道の八つの場面で、音楽と環境音に包まれながら、ポモドーロタイマー・タスク・カレンダー・リマインダー・メモ・付箋・記録を使えるチルソフトです。カジュアルな時計（SUIKYO CLOCK）にも切り替えられます。

iPhone の横向きで、ホーム画面から全画面アプリとして使うことを前提に作っています（PWA）。

## できること

- **八つの部屋**：場面ごとの景色・時計・環境音・音楽。場面サムネイルのタップか 1〜8 キーで切り替え
- **過ごし方**（左上の部屋名をタップ）：勉強・作業／読書／睡眠／瞑想・深呼吸／休憩／在宅ワークのBGM／子どもの学習。部屋・音・道具をワンタップでひと揃えに
- **道具**（右下）：タイマー（ポモドーロ・好きな長さ・ストップウォッチ）、カレンダー、リマインダー、タスク、サウンド（音楽と環境音のミキサー、おやすみタイマー）、メモと付箋、記録（7日間・月ごと）、深呼吸
- **操作**：タスクは右へスワイプで完了・左へで削除（取り消し可）・長押しでメニュー。左のシートは左へはらうと閉じる
- **設定**（過ごし方の下、または , キー）：日本語／English、文字の大きさ（iPhone の設定に追従も可）、操作音、透明度を下げる、集中中は画面を消さない
- **カジュアル**：右上の「チル｜カジュアル」で、別デザインの時計・タスク・アラームに切り替え（タスクは共有）

- 公開URL：<https://uankoro.github.io/CELL/>
- 対応：iPhone（iOS 16.4 以降推奨）の横向き。iPad・PC のブラウザでも動きます
- データ：すべてこの端末の中（ブラウザのローカルストレージ）に保存されます。サーバーには送りません

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JavaScript をこの1ファイルに収録） |
| `manifest.json` | ホーム画面に追加した時の名前・アイコン・横向き全画面の設定 |
| `sw.js` | Service Worker。オフライン起動とキャッシュを担当 |
| `icons/` | アプリアイコン（180・192・512px と Android 用の maskable） |
| `.nojekyll` | GitHub Pages に Jekyll の変換をさせないための空ファイル |
| `tests/`・`playwright.config.mjs`・`package.json` | 自動テスト（公開には不要。GitHub Pages には配信されても動作に影響なし） |
| `docs/QUALITY.md` | Lighthouse などの計測結果 |

すべての参照は相対パスなので、`/CELL/` のようなサブパス配下でもそのまま動きます。

## GitHub Pages での公開手順

1. GitHub でこのリポジトリ（`uankoro/CELL`）を開く
2. 上部の **Settings** → 左メニューの **Pages** を開く
3. **Build and deployment** の **Source** で「**Deploy from a branch**」を選ぶ
4. **Branch** で `main`、フォルダは `/ (root)` を選んで **Save**
5. 1〜2分待つと、同じ画面の上部に公開URLが表示されます
   - 公開URL：**<https://uankoro.github.io/CELL/>**
   - リポジトリの **Actions** タブで「pages build and deployment」が緑になれば完了です

以降は `main` に変更をマージするたびに自動で再公開されます。

### 更新を配信するとき

`sw.js` 冒頭の `VERSION`（例：`'v2.0.0'`）を必ず上げてからマージしてください。
新しいバージョンのキャッシュが作られ、古いキャッシュは自動で削除されます。
アプリは「まずキャッシュから即座に表示し、裏で最新版を取得する」方式なので、更新は**次に開いたとき**に反映されます。

## iPhone のホーム画面に追加する方法

1. iPhone の **Safari** で <https://uankoro.github.io/CELL/> を開く（Chrome など他のブラウザではなく Safari で）
2. 画面下の **共有ボタン**（四角から上向き矢印のアイコン）をタップ
3. メニューを下へスクロールして **「ホーム画面に追加」** をタップ
4. 名前が「CELL」になっていることを確認して、右上の **「追加」** をタップ
5. ホーム画面の CELL アイコンから起動すると、アドレスバーのない全画面で開きます

使い方のポイント：

- **横向きで使います。** 縦向きにすると「横向きにしてください」という案内が出て操作が止まります。横に戻せば、音楽やタイマーはそのまま続きから使えます
- 画面の向きが変わらない場合は、コントロールセンターの「画面縦向きのロック」をオフにしてください
- 一度開けば、**機内モードやオフラインでも起動**できます
- 最初の「入室する」をタップすると音が出ます（iPhone の消音スイッチがオンだと聞こえない場合があります）

### データの引っ越しについて（重要）

iOS では、**Safari で開いた CELL と、ホーム画面から開いた CELL は保存場所が別**です。
Safari で使っていたタスクやメモをホーム画面版に移したいときは：

1. Safari 版で、右下のツールから **記録** → **データの引っ越し** → **書き出してコピー**
2. ホーム画面版で、同じく **記録** → **データの引っ越し** → **読み込む** に貼り付けて **上書きして読み込む**

機種変更のときも同じ手順で移せます。

## テスト

Playwright で、WebKit（Safari と同じエンジン）と Chromium の両方を、iPhone SE／標準／Pro Max の横向き・タッチ操作で自動テストしています。
プルリクエストごとに GitHub Actions（`.github/workflows/test.yml`）でも実行されます。

```sh
npm ci
npx playwright install --with-deps webkit chromium   # 初回のみ
npm test                  # すべて
npm run test:webkit       # WebKit だけ
npm run test:chromium     # Chromium だけ
```

テストはコンソールのエラー・警告が1件でも出れば失敗にしています。内容は `tests/` を参照（既存機能の総点検、PWA・オフライン、旧データの移行、ジェスチャー、新機能、英語表示、アクセシビリティ、長時間稼働、応答性）。品質の計測結果は `docs/QUALITY.md` にあります。

## ローカルで確認する

`file://` で直接開いても動きますが、Service Worker（オフライン機能）は `http(s)` でのみ有効です。

```sh
npm run serve
# → http://localhost:4173/CELL/ を開く（GitHub Pages と同じサブパス）
```

ブラウザの開発者ツールで iPhone の横向き（例：844×390）を指定すると、スマホ向けのレイアウトを確認できます。
